# Asset slots

Keep final local assets in this directory or `public/media/`.

- `hero/`: personal portrait or environmental image, ideally 2400px wide.
- `travel/`: city photographs, named `{city}-{sequence}.webp`.
- `music/`: square cover art, named `{track-slug}.webp`.
- `game/`: original concept art for Clockwork Garden, Echo City, and Starlight Workshop.
- `audio/`: optional locally licensed preview clips in `.mp3` or `.ogg`.

Use owned, commissioned, CC-compatible, or properly licensed assets only. Every image used in the UI needs descriptive alt text in `siteContent.ts`.
