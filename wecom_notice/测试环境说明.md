## 🚀 快速开始

### 方式1: 使用测试脚本（推荐）

```bash
# 测试模式（发送到测试群）
python test_wecom.py

# 生产模式（发送到正式群）
python test_wecom.py --prod
```

测试脚本提供3个测试用例：
1. **简单消息** - 发送基础文本消息
2. **@提醒** - 测试@群内成员功能
3. **真实通报** - 使用实际数据生成通报（需确认后发送）

### 方式2: 通过环境变量

```bash
# 启用测试模式
set WECOM_NOTICE_TEST_MODE=true

# 启动API服务
python -m uvicorn wecom_notice.api:app --host 0.0.0.0 --port 8996 --reload
```

### 方式3: Python代码

```python
import os
os.environ["WECOM_NOTICE_TEST_MODE"] = "true"

from wecom_notice.sender import send_text
from wecom_notice.config import TEST_PERSONNEL

# 发送测试消息
message = "这是一条测试消息"
result = send_text(message, TEST_PERSONNEL)
print(result)
```

## 📝 金山文档脚本部署

### 脚本位置
```
scripts/airscript_qywx_notice_upload.js
```

### 部署步骤

1. **打开金山文档的AirScript编辑器**
   - 登录金山文档
   - 找到目标多维表格
   - 进入「扩展功能」→「AirScript」

2. **复制脚本内容**
   ```bash
   # 查看脚本内容
   cat scripts/airscript_qywx_notice_upload.js
   ```

3. **粘贴到AirScript编辑器**
   - 全选并粘贴整个脚本
   - 保存脚本

4. **配置触发器**
   - 设置为webhook触发
   - 或设置定时触发（如每天8:00）

5. **测试脚本**
   - 点击「运行」测试
   - 查看日志确认上传成功

### 脚本功能说明

- **读取字段**：22个预约表格字段（客户经理姓名、预约日期、拜访对象等）
- **分页读取**：自动处理大量数据（每页100条）
- **过滤空行**：只上传有效数据
- **服务器地址**：`https://shanguantang.site/api/airscript/upload`

## 🔍 故障排查

### 问题1: 消息发送失败
**可能原因：**
- Webhook URL配置错误
- 网络连接问题
- 机器人已被移除

**解决方法：**
```bash
# 检查webhook配置
python -c "from wecom_notice.config import TEST_WEBHOOK_URL; print(TEST_WEBHOOK_URL)"

# 测试网络连接
curl https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=866c5319-0f4a-42fe-8465-f4b3de554c61
```

### 问题2: @提醒无效
**可能原因：**
- 手机号格式错误
- 人员未加入群聊
- 机器人权限不足

**解决方法：**
- 确认手机号正确（11位数字）
- 确认人员已在群聊中
- 检查机器人配置

### 问题3: 金山文档数据未同步
**可能原因：**
- AirScript脚本未运行
- 服务器地址错误
- 数据格式不匹配

**解决方法：**
```bash
# 查看最近上传记录
python -c "from wecom_notice.db import latest_upload; print(latest_upload())"

# 检查API日志
# 查看 uvicorn 控制台输出
```
