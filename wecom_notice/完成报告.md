## 🚀 快速开始

### 1. 安装依赖
```bash
cd morning_report
pip install APScheduler>=3.10.0
```

### 2. 配置环境变量
在 `.env` 文件中配置企业微信webhook：
```bash
WECOM_NOTICE_WEBHOOK_URL=https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=YOUR_KEY
```

### 3. 测试功能
```bash
python wecom_notice_cli.py test
```

### 4. 启动服务
```bash
# 方式1: 使用CLI工具
python wecom_notice_cli.py start

# 方式2: 直接启动
python wecom_notice/main.py
```

### 5. 启动调度器
```bash
curl -X POST http://127.0.0.1:8996/api/scheduler/start
```

## 📝 关键设计决策

### D1: 图片发送方案
**决策**: 先实现Excel导出+下载功能，暂不实现自动发送图片到企业微信  
**原因**: 
- 企业微信webhook不支持直接上传图片
- 需要企业微信应用接口（额外权限配置）
- Excel已能满足大部分需求

### D2: 定时任务框架
**决策**: 使用APScheduler BackgroundScheduler  
**原因**:
- Python原生支持，无需额外服务
- 支持cron表达式
- 轻量级，适合当前规模（20个任务）

### D3: 调度器启动方式
**决策**: 调度器默认不自动启动，需要手动通过API启用  
**原因**:
- 避免误触发大量通知
- 便于测试和调试
- 给予用户完全控制权

## ⚠️ 注意事项

### 1. 企业微信配置
- 需要配置`WECOM_NOTICE_WEBHOOK_URL`环境变量
- 如需@功能，需配置人员的`mobile`或`wecom_userid`
- webhook有频率限制，注意不要过于频繁发送

### 2. 数据初始化
- 首次运行会自动创建数据库表
- 统计功能依赖历史数据，初期统计结果可能为空
- 需要金山文档定时发送数据到服务器

### 3. 时区和时间
- 所有时间均为本地时间（服务器时区）
- 确保服务器时间正确
- 定时任务在指定时间触发，误差在秒级

### 4. 性能考虑
- 20个定时任务并发执行无压力
- 数据库已添加索引，查询性能良好
- Excel导出速度快，文件大小<10KB

## 🔧 故障排查

### 问题1: 调度器启动失败
**原因**: APScheduler未安装  
**解决**: `pip install APScheduler>=3.10.0`

### 问题2: @功能不生效
**原因**: 未配置mobile或wecom_userid  
**解决**: 在`config.py`中配置人员信息

### 问题3: 定时任务不执行
**原因**: 调度器未启动  
**解决**: 调用`POST /api/scheduler/start`启动

### 问题4: 企业微信发送失败
**原因**: webhook URL未配置或无效  
**解决**: 检查`.env`文件中的`WECOM_NOTICE_WEBHOOK_URL`
