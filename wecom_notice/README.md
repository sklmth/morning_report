# 企业微信预约填报通知系统

自动监控客户经理次日预约填报情况，按时向企业微信发送提醒和通报。

---

## 通知时间表

| 通知类型 | 发送时间 | 发送对象 | 触发条件 |
|---|---|---|---|
| 客户经理个人提醒 | 18:00 / 18:45 / 19:15 / 19:45 / 20:15 / 21:00 / 22:00 / 23:00 | 各客户经理（个人） | 未达 2 户才发，达标跳过 |
| 简洁通报（张端） | 18:30 / 19:00 / 19:30 / 20:00 / 20:30 / 21:00 / 21:30 | 张端副经理 | 仍有人未填时发送 |
| 简洁通报（钟俊杰） | 19:00 / 19:30 / 20:30 / 21:00 / 21:30 | 钟俊杰经理 | 仍有人未填时发送 |
| 详细通报 | 22:00 | 全体管理者 | 每日固定发送 |
| 最终数据收集 | 23:30 | —（不发消息） | 判定填报状态，写入统计表 |

每次通知发送前自动从金山文档同步最新数据；同一时段多个任务共用一次同步，5 分钟内不重复拉取。

## 通报示例

### 1. 客户经理个人提醒（发给本人）

```
📋 @麦海芬

明日预约填报提醒（第2次）
📅 日期：2026-08-04
✅ 已填：1 户
⚠️ 还需：1 户

📊 本月记录：
   ⏱️ 超时填报：3 次
   ❌ 漏填：1 次

💡 温馨提示：请尽快完成填报，确保明日工作顺利开展~
```

开启下午茶基金提醒后，末尾追加：

```
☕ 下午茶基金提醒：
   · 本月漏填 1 次（× 10 元/次）= 10 元
   请上交 10 元至部门下午茶基金。
```

> 已填报 ≥ 2 户时本条消息不发送。"本月记录"仅在有超时或漏填时显示。

---

⚠️ 未完成填报：
❌ 麦海芬：已填报 0 户，还差 2 户
❌ 李东：已填报 1 户，还差 1 户
❌ 具进康：已填报 0 户，还差 2 户

✅ 已完成填报：
✅ 黄淡妮：已填报 2 户

✅ 麦海芬：2 户
    · 广州市XX区政府（高装：程庆德）
    · 广州电信集团（智云：零樑）
✅ 黄淡妮：2 户
    · XX单位（未指定：无）

━━━━━━ 📈 累计填报情况 ━━━━━━

👍 准时填报（19:30前完成）：
   🎉 黄淡妮：8 次
   🎉 邱海燕：6 次

> 交付类型根据"预约交付人员姓名"字段自动判断：高装人员 → 高装，智云工程师 → 智云，其余 → 未指定。

## 填报状态说明

| 状态 | 判定条件 |
|---|---|
| 准时（on_time） | 23:30 前已填 ≥ 2 户，且最后一条记录上传时间 ≤ 19:30 |
| 超时（overtime） | 23:30 前已填 ≥ 2 户，但最后一条记录上传时间 > 19:30 |
| 漏填（missing） | 23:30 时仍未达到 2 户 |

## 下午茶基金（可选）

在前端「系统」Tab 的「☕ 下午茶基金提醒」开关开启后，客户经理个人提醒中自动附加罚款计算：

| 触发条件 | 金额 |
|---|---|
| 本月漏填 N 次 | N × 10 元 |
| 本月超时填报累计满 5 次 | 每满 5 次 10 元 |

两项合计为 0 时不显示该提醒块。

## 快速开始

```bash
# 安装依赖
pip install APScheduler>=3.10.0

# Webhook 已内置端州政企群地址（config.py 的 DEFAULT_WEBHOOK_URL），无需配置。
# 要发到其他群时才需覆盖：
# WECOM_NOTICE_WEBHOOK_URL=https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=YOUR_KEY

# 启动服务
python wecom_notice/main.py
# 服务运行在 http://127.0.0.1:8996
```

启动后在前端「系统」Tab 手动开启调度器，或调用：
```bash
curl -X POST http://127.0.0.1:8996/api/scheduler/start
```

## 常用 API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/scheduler/status` | 调度器状态及任务列表 |
| POST | `/api/scheduler/start` | 启动调度器 |
| POST | `/api/scheduler/stop` | 停止调度器 |
| POST | `/api/scheduler/trigger/{job_id}` | 手动立即执行某任务 |
| POST | `/api/kingsoft/trigger-sync` | 手动触发金山文档同步 |
| GET | `/api/statistics/cumulative` | 累计填报统计 |
| GET | `/api/statistics/export` | 导出 Excel |
| GET | `/api/config/settings` | 读取应用设置（含罚款开关） |
| POST | `/api/config/settings` | 保存应用设置 |
| GET | `/docs` | FastAPI 自动生成的接口文档 |

## 文件结构

```
wecom_notice/
├── main.py              # 服务入口（端口 8996）
├── api.py               # FastAPI 路由
├── config.py            # 人员名单、Webhook 配置
├── db.py                # SQLite 操作（含 app_settings）
├── parser.py            # 金山文档字段解析
├── reporter.py          # 各类通报构建器
├── sender.py            # 企业微信消息发送
├── scheduler.py         # APScheduler 定时任务
├── kingsoft_trigger.py  # 触发金山文档回调
├── excel_export.py      # Excel 导出
└── frontend/            # 前端（Alpine.js + Tailwind CSS）
```
